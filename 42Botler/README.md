# 🇩🇪 42Botler – Campus AI Assistant

**AI-powered student support · 42 Heilbronn, Germany**

> Campus information, coding standards, and resources — one conversational interface.

- **Event:** Unlock Campus Hackathon
- **Date:** October 2025
- **Team:** Team Cooked, representing 42 Heilbronn

## 🎯 Challenge

Students need to find campus information, understand coding standards, and locate useful resources without searching across many sources.

## 💡 Team Solution

Team Cooked built an AI-powered student support chatbot that brings these needs into a single conversational interface:

- **Campus information** to help students find what they need.
- **Coding standards** as a reference for development.
- **Useful resources** accessible through conversation.

## 🛠️ Technologies

**React · Node.js · AI / retrieval-augmented generation (RAG)**

The project combined a React frontend and a Node.js backend with AI/RAG capabilities.

## 🤝 Collaboration & Learning

This project was built collaboratively by **Team Cooked**. I value the opportunity to explore a practical use of AI for student support and to learn from teammates while working toward a shared solution.

Thanks to the team for the shared ideas and teamwork. The original repository, maintained under [ExceptedPrism3](https://github.com/ExceptedPrism3), provides project details and contributor information.

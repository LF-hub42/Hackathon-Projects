## 🤖 42Botler — Campus AI Assistant

> Campus information, coding standards, and resources — one conversational interface.

**Unlock Campus · 42 Heilbronn · October 2025**

- **Team:** Team Cooked
- **Technologies:** React · Node.js · AI / retrieval-augmented generation (RAG)

### The challenge

Students need to find campus information, understand coding standards, and locate useful resources without searching across many sources.

### The solution

Team Cooked built an AI-powered chatbot that brings these needs into a single conversational interface, combining a **React frontend**, a **Node.js backend**, and **AI/RAG capabilities**.

**[Try the public demo ↗](https://42botler.prism3.me/)**

Original repository: [ExceptedPrism3/42-Hackaton-42Botler](https://github.com/ExceptedPrism3/42-Hackaton-42Botler)

## 🌱 S³ — Škoda Smart Stream

> Connecting employee development needs with relevant learning opportunities.

**Škoda Auto × 42 Prague · November 2025**

- **Team:** DO_IT, representing 42 Heilbronn
- **Technologies:** Next.js · TypeScript · Python

### The challenge

Organizations need ways to understand skill gaps and help employees identify relevant learning and development opportunities.

### The solution

Team DO_IT created an **AI-powered learning and development platform** featuring:

- **Skill-gap analysis** to identify development needs.
- **Personalized learning recommendations** to guide employee learning.
- **HR insights** to support an organizational view of development.

The solution used a **Next.js and TypeScript application** alongside **Python components**.

> 🔒 **Restricted demo:** Access is unavailable because the demo contains internal company data.

Original repository: [ExceptedPrism3/42-Hackaton-Skoda](https://github.com/ExceptedPrism3/42-Hackaton-Skoda)

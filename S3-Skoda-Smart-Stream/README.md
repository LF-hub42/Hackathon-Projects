# 🇨🇿 S³ – Škoda Smart Stream

**AI-powered learning and development · 42 Prague, Czech Republic**

> Connecting employee development needs with relevant learning opportunities.

- **Event:** AI Skill Coach Hackathon, organized in collaboration with Škoda Auto
- **Date:** November 2025
- **Team:** DO_IT, representing 42 Heilbronn

## 🎯 Challenge

Organizations need ways to understand skill gaps and help employees identify relevant learning and development opportunities.

## 💡 Team Solution

Team DO_IT created an AI-powered learning and development platform featuring:

- **Skill-gap analysis** to identify development needs.
- **Personalized learning recommendations** to guide employee learning.
- **HR insights** to support an organizational view of development.

## 🛠️ Technologies

**Next.js · TypeScript · Python**

The solution used a Next.js and TypeScript application alongside Python components.

## 🤝 Collaboration & Learning

This project was built collaboratively by **Team DO_IT**. I value the opportunity to explore how AI and product thinking can connect employee needs with learning opportunities, and to learn through shared problem-solving.

Thanks to the team for the shared ideas and teamwork. The original repository, maintained under [ExceptedPrism3](https://github.com/ExceptedPrism3), provides project details and contributor information.
